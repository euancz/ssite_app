# SSITE mobile

SSITE is a Flutter client with a standalone Dart backend. The service reads and writes the same PostgreSQL tables and attachment storage as SSITECMS. Members use their existing Microsoft school identity. Officers, the President, advisers and admins receive tools based on their current account permissions.

See [setup](docs/SETUP.md) to run the service and the app, and [the source map](docs/DEBUGGING.md) to locate a feature.
